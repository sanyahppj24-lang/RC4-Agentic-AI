What is a cipher?
A cipher is an algorithm or mathematical process used to perform encryption and decryption. It acts as a set of rules that translates an original, readable message (plaintext) into a scrambled, unreadable format (ciphertext) and vice versa, typically to ensure secure communication.

So in this project, we are going to use LangGraph for dynamic stateful workflows. Here, nodes can communicate with each other. Old memory persists, which is necessary to obtain new data. Agents can make their autonomous decisions without the intervention of the developer. Loops work automatically; they don’t wait for the developer's answers. So LangGraph turns normal scripts into a decision-driven AI workflow graph.

In langgraph:-
States :- shared memory between all agents (e.g., RC4 is a state that is shared with all nodes)
Nodes: Agents
Edges:- Connections(like connects nodes or agents)
Conditional Edges: Dynamic routing(as in joining nodes as per condition)
Loops: Self-correction


All nodes read the state because it is something same for all nodes. Modifies it and returns the updated state.

The project uses LangGraph to build a stateful multi-agent workflow for autonomous RC4 cryptanalysis. Instead of using fixed scripts, the system dynamically generates experiments, analyzes RC4 keystream biases, evaluates statistical confidence, stores historical memory, and uses reinforcement learning to adapt its future decisions. LangGraph enables conditional routing, looping, and state sharing between agents, making the workflow autonomous and agentic rather than linear automation.

LangGraph is like a smart metro map for AI agents.

Each station is a node (agent).
Tracks are edges.
State is the passenger information carried between stations.
Conditional routing changes which track to take.
Loops allow revisiting stations for correction.
END stops the journey.
